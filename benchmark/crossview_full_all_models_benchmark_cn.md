# Crossview 已训练模型统一评测

本文档用于可视化记录 `outputs/mapanything_experiments/mapanything/training/Crossview` 下参与评测的全部模型及关键指标。原始逐模型、逐 scene 全量结果仍保存在 `outputs/mapanything_experiments/mapanything/benchmarking/rs_guided_dense_mv` 下；本文档不展开所有原始字段。

## 评测口径

- 数据：沿用 `docs/crossview_all_models_benchmark_cn.md` 的统一 Crossview 评测流程，但不再使用 mini subset。
- 测试集：使用 `benchmark_vigor_chicago_rs_aerial` 的 paired split；若当前配置仍指向 `val` split，则本轮需显式记录为 paired val。
- 样本数：先固定两个典型规模 `n_scenes=2` 与 `n_scenes=8`，用于快速但可对比的简要评测。
- 输入：`NUM_VIEWS=4`，`BATCH_SIZE=1`；评测可按 GPU 分片并行跑多个 checkpoint。
- 分辨率：Pi3/VGGT 使用 518；VGGT-Omega 使用 512，除非模型训练配置另有明确要求。
- 卫星输入：只评测真实匹配卫星图下的 Joint 输入；不做 `same`、`blank`、`shuffled` 对照。
- 结果根目录：建议使用 `outputs/mapanything_experiments/mapanything/benchmarking/rs_guided_dense_mv/crossview_all_models_4v_n2_n8`，其下按 `n_scenes` 和模型名保存原始 JSON。
- 训练 checkpoint 根目录：`outputs/mapanything_experiments/mapanything/training/Crossview`。

指标方向：

- 越低越好：`pointmaps_abs_rel`、`z_depth_abs_rel`、`pose_ate_rmse`、`ray_dirs_err_deg`、`joint_global_pointmaps_abs_rel`、remote 点图误差、remote 高度误差。
- 越高越好：`pose_auc_5`。
- 相对差值统一写作 `(joint - aerial) / aerial` 或 `(joint_remote - remote_only) / remote_only`；负数表示误差类指标变好，正数表示 AUC 类指标变好。
- 卫星输入收益：专指 `Aerial-only` 与 `Joint aerial` 的差，即加入真实卫星图后 aerial 侧指标的变化。

本轮正式报告字段：

- Aerial-only：`pointmaps_abs_rel`、`z_depth_abs_rel`、`pose_ate_rmse`、`pose_auc_5`、`ray_dirs_err_deg`。
- Joint aerial：`pointmaps_abs_rel`、`z_depth_abs_rel`、`pose_ate_rmse`、`pose_auc_5`、`ray_dirs_err_deg`、`joint_global_pointmaps_abs_rel`。
- Aerial -> Joint 相对差值：对上面共同 aerial 指标逐项计算。
- Remote-only：`remote_pointmaps_abs_rel`、`remote_pointmaps_l1`、`remote_pointmaps_abs_rel_scale_aligned`、`rs_height_mae_affine`、`rs_height_rmse_affine`。
- Joint remote：`joint_remote_pointmaps_abs_rel`、`joint_remote_pointmaps_l1`、`joint_remote_pointmaps_abs_rel_scale_aligned`、`joint_rs_height_mae_affine`、`joint_rs_height_rmse_affine`。
- Remote -> Joint remote 相对差值：对 remote 点图和高度指标逐项计算。
- 未微调基线：加入 `pi3_raw_pretrained_image_input` 与 `vggt_raw_pretrained_image_input`，不加载 Crossview checkpoint，remote 作为普通图像输入参与 Remote-only 与 Joint 评测。

字段映射说明：`remote_pointmaps_abs_rel` / `joint_remote_pointmaps_abs_rel` 映射自 `rs_point_abs_rel`。从当前修订起，`rs_point_abs_rel` 使用 remote 自身作为 view0，去平移并按 GT remote 点图尺度归一化；旧的全局坐标 abs-rel 保留为 `rs_point_abs_rel_global`，只用于排查，不进入主榜。

状态说明：下方已填数值来自旧 remote 全局口径评测；修正 remote 指标和加入未微调基线后，需要重跑对应模型才能刷新表格。
